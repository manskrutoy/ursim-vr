# UrSim VR

Неофициальный VR-мод для **UrSim** — симулятора FIRST Tech Challenge BIOBUZZ от **URAN92**.
Все права на игру, модели и код принадлежат её автору; этот репозиторий только добавляет VR-режим (WebXR).

**Играть:** открой ссылку на GitHub Pages в браузере Meta Quest, выбери робота, нажми «Старт», затем «Войти в VR».
Ты стоишь на месте драйвера за стеной своего альянса, в реальном масштабе.

Управление: контроллеры Quest (стики, триггеры, grip, A/B/X/Y; клик обоими стиками — пауза)
или геймпад PS4/PS5/F310/Xbox. Перецентровка — зажать кнопку Meta.

Код мода: [`vr/ursim-vr.js`](vr/ursim-vr.js).
